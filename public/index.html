⚠️ Sunday Morning Quick Fixes

🚨 "Silence Detected" Alarm Flashing

Audio is dead for >2 min. Check: 1) Is REAPER master fader muted? 2) Is the USB interface unplugged? 3) Is the church soundboard master fader down?

⚠️ REAPER Shows "Offline"

Check if REAPER is open. In REAPER Preferences > Control/OSC/web, ensure Device Port is set to 9000.

⚠️ OBS Shows "Offline"

In OBS: Tools > WebSocket Server Settings > Ensure "Enable WebSocket server" is checked on port 4455.

⚠️ Proclaim Shows "Offline"

In Proclaim on presentation PC: Settings > Remote > Enable Remote and verify network password matches Tab 2.

Quick First-Time Connection Steps
REAPER OSC

In REAPER: Preferences > Control/OSC/web > Add OSC with Mode = OSC, IP = 127.0.0.1, Port = 9000.

ATEM Mini LAN

Connect Ethernet to church router. Paste its static IP (e.g. 192.168.1.240) in Tab 2.

OBS WebSocket

In OBS: Tools > WebSocket Server Settings > Check "Enable WebSocket server" (port 4455).

Proclaim Remote

In Proclaim: Settings > Remote > Enable and note password. Enter IP & password in Tab 2.
